STARBOUND FRONTIER — DEVELOPMENT WEBSITE

HOW TO PREVIEW
1. Extract this folder/ZIP.
2. Open index.html in Chrome, or open the folder in VS Code and use Live Server.
3. Tick tasks as you complete them. Checklist progress saves in that browser on that device.

HOW TO EDIT
- Edit index.html in any text editor or VS Code.
- Replace or add images in the assets folder and update the matching src paths.
- The checklist is intentionally unchecked: your supplied notes list planned tasks, not which are complete.
- The release date and technology choice are marked undecided because the notes say these decisions are still open.

PUBLISHING
You can host this as a static website using GitHub Pages. Do not publish private information or anything you do not have permission to share.
